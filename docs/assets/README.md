# Paper figures

These figures are reproduced from the manuscript
*Deformation-Aware Mesh Refinement for Robust Automatic Rigging*:

- `observations.png`: Fig. 1, from `Fig1_observations.pdf`.
- `pipeline.png`: Fig. 2, from `Fig2_pipeline.pdf`.

The author supplied the PDFs for use in this repository. The PNGs are rendered
at 2,400 pixels wide on a white background, without cropping or changing content.
